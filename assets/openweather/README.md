# Logo OpenWeather

`openweather-logo.png` é a cópia sem alterações do logo oficial RGB, obtida
no [pacote de logos](https://openweathermap.org/payload/api/files/file/logo_files.zip)
indicado pela [FAQ de atribuição](https://openweathermap.org/faq).

Arquivo de origem no pacote:
`Logo files/Master logo/RGB (for screen)/OpenWeather-Master-Logo RGB.png`.

O logo é usado para acompanhar o crédito
**Weather data provided by [OpenWeather](https://openweathermap.org/)**.
É um recurso de marca de terceiros, excluído da licença Apache 2.0 do projeto.
Seu uso não indica endosso do FarmNote pelo OpenWeather. Ao redistribuir dados
ou funcionalidades derivadas, preserve o crédito, o link e o logo conforme
as [orientações de atribuição](../../docs/third_party_licenses.md).
